# Initial Research Proposal & Pre-Paper Abstract

## Title
**Design and Implementation of an Automated AI-Proctored Placement Assessment and Employability Evaluation Platform**

---

## Abstract
Campus recruitment and placement evaluations in modern technical institutions face critical challenges regarding candidate verification, remote exam integrity, automated code execution grading, and real-time skill diagnostics. Existing assessment systems often lack integrated computer vision proctoring or rely on expensive proprietary third-party solutions.

This paper proposes **MITRA Employability Portal**, an open-source, full-stack MERN platform featuring browser-based automated face detection (`face-api.js`), LLM-driven question generation, isolated compiler sandboxes, and psychometric evaluation suites to streamline institutional placement workflows.
