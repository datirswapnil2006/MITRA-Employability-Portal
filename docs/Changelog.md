## [1.0.0] - 2026-08-03

### Added
- Complete MERN stack role-based assessment portal.
- Admin registration queue approval flow.
- AI-based proctoring module using `face-api.js` for tab switch and webcam face detection.
- Timed assessment engine supporting MCQ and Coding questions.
- Live code execution sandbox supporting Python, C++, Java, and JavaScript via Piston API.
- AI Question Generator powered by HuggingFace API.
- PDF exam paper parser and question extractor (`pdf-parse`).
- Psychometric evaluation suite and student study materials repository.
- Student AI Self-Test practice suite with instant score breakdown and analytics.
- Standardized enterprise GitHub repository layout and comprehensive technical documentation.
